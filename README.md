### Getting started

1) Clone [gvastethecreator/vscode-paste-image-next](https://github.com/gvastethecreator/vscode-paste-image-next), then run `pnpm install`.
2) Press F5 (`Run Extension`).
3) Copy an image, then run **Paste Image**.
